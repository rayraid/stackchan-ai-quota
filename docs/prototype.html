桌面 AI 额度小摆件：三种屏幕风格

先在下面切换场景，再对比三种风格在同一场景下的样子。点屏幕等于在真机上点触摸屏。我按 M5Stack StackChan 来画：2 英寸 320×240 触摸屏，头能左右转、上下点，带彩灯和喇叭。最终做进固件的是 A 表情优先，提醒强度是「中」；B 和 C 留在这里作对照。

A 风格的全部表情

「做完了」和「要你批准」是两张不同的脸：做完了是笑脸，要你批准是睁大眼加感叹号。气泡、灯和动作两种情况相同。

CodexBar 能拿到「AI 在等你」的信号吗

能拿到一半。下面是用 CodexBar 0.84 的命令行实测的结果。

我们需要的结论实测情况
各订阅剩余额度能启用的订阅，命令行都能读到。Claude 起初读不到，在钥匙串里给命令行授权一次后解决。
额度快用完、已重置能自带额度事件功能，默认关闭。打开后在快用完、用完、重置时会主动通知。
把数据送到局域网能自带一个小型网页服务，设备可以直接来取数，需要设口令。
哪个 AI 在等你回复一半有会话列表，但只分「在干活」和「空闲」两种状态，只认 Claude Code 和 Codex。分不出「卡在等你授权」，也看不到 Cursor、OpenCode、Antigravity。

所以额度全部交给 CodexBar，「等你回复」交给第二个工具 peon-ping。两个工具加一个小管家，已经接通并实测过。

GitHub 上有没有现成的

有不少相近的，但没有一个同时做到三件事：读 CodexBar 的多家额度、接多种 AI 的提醒、让 StackChan 动起来。可以借的部分如下。

peon-ping给 20 多种 AI 工具接了「做完了」和「需要你输入」两类信号，用来播音效。MIT 协议，约 5 千星。直接用它：已经装上并静音，由它盯住各个 AI 工具，把信号转给小管家。
agentface32ESP32 小屏上显示多个 AI 的状态脸，参考机型是同样 320×240 的 M5Stack Basic。MIT 协议。不显示额度，不会动。借它：电脑把信号发给设备的做法。
StackChan 提醒实战记录有人让 StackChan 在 Claude Code、Codex、Antigravity 做完任务时转头说话。没公开源码。借它：踩过的坑。比如 Claude Code 空闲 60 秒会重复提醒，要过滤掉。
m5-stopwatch、Codey、Clawdmeter在 ESP32 小屏上显示 Claude（有的加 Codex）的额度。只认一两家，不走 CodexBar。借它：小屏上额度条的排版思路。

它怎么工作

CodexBar提供各订阅的剩余额度
peon-ping盯住各个 AI 工具，谁在等你授权、提问或做完了，就发一个信号
本机
Mac 上的小管家一个后台小程序。每隔几分钟问一次 CodexBar，随时接收「等你回复」信号，整理成一份很小的状态。
WiFi
StackChan只负责显示、转头、亮灯、出声。你摸它的头，它把「知道了」传回去。

实施步骤

  1. 先做 Mac 上的小管家，不碰硬件（已完成）读 CodexBar 的额度，接上 peon-ping 的「等你回复」信号，做了一个用真实数据驱动的模拟器。 现在能看到：小管家运行时，在运行小管家的 Mac 上打开 http://127.0.0.1:8787/ ，假设备跟着真实情况变。
  2. 设备固件第一版（已完成）装好开发工具，设备连上了 WiFi，画出 A 风格的全部画面，显示真实额度。 现在能看到：真机屏幕上是各家订阅的真实额度。
  3. 提醒动作（已完成）点头、摇头、彩灯、提示音，以及摸头表示「知道了」。 现在能看到：Claude Code 一问你，它就点头、亮琥珀色灯、响一声。
  4. 接入其余 AIClaude Code 已接通。Codex、Cursor、OpenCode、Antigravity 在 peon-ping 里逐个打开，每个单独验证。 做完能看到：任何一个在等，它都知道。
  5. 收尾开机自动运行、夜间静音、断线时的表现、屏幕亮度。

已知问题和待确认

  • 5 家额度都由 CodexBar 命令行读取，每 5 分钟一次。读 Claude 靠的是 Claude 桌面版的登录状态，所以 Claude 桌面版要保持登录。某一家命令行读不到时，会用 CodexBar 应用写出的共享文件顶上。
  • peon-ping 本来是播放游戏音效的工具，现在音量调成了 0，只保留信号。不要用它的「暂停」功能，那会连信号一起停掉。
  • Antigravity 的「等你回复」信号最不确定。开源做法是读它的日志文件来推断，准确度要实测。
  • 我们自己没有加钩子，钩子是 peon-ping 安装时登记的。它只追加自己的条目，不会动其他工具已有的钩子。
  • 设备要和 Mac 在同一个 WiFi。Mac 睡着时设备会显示「连不上 Mac」。
  • 真机上的字比这页原型里的大。屏幕只有 2 英寸，实际用过后把字整体放大了，列表页因此不再显示恢复时间，气泡第二行改成原因在前、项目名在后。
  • 提醒强度目前固定是「中」，「轻」和「强」还没有做成可切换；夜间静音和屏幕亮度也还没做。
